# yx-artifacts

Копии файлов, которые качают облачные ВМ: Linux-агент `yxman2` и плеер
`moonvanila`. Оригиналы лежат на `https://yx.ru.net/dl/<канал>/<версия>`.

Каждая версия — отдельный релиз `<канал>-<версия>` с одним файлом. Файлы
кладёт workflow `mirror` раз в 5 минут. Перед выкладкой он сверяет sha256
с тем, что отдаёт бэкенд. Руками сюда ничего не заливается.

ВМ качают файл отсюда, sha256 сверяют сами. Если GitHub недоступен или файл не
сошёлся, ВМ берут его с `yx.ru.net`.

Запустить копирование сразу, не дожидаясь cron:

```bash
gh workflow run mirror --repo flooovvv/yx-artifacts
```
